# Projeto 01 - API para PostgreSQL com n8n

Pipeline ETL desenvolvido com n8n para consumir dados de uma API REST pública, transformar os dados e persisti-los em um banco PostgreSQL.

## Tecnologias

- n8n
- PostgreSQL
- REST API
- JSON
- SQL

## Arquitetura

HTTP Request
↓
Transformação dos dados
↓
PostgreSQL
↓
Pipeline Completed

## Objetivo

Demonstrar conhecimentos em:

- ETL
- Integração entre APIs
- Automação de workflows
- Banco de dados PostgreSQL
- Manipulação de JSON
- SQL
